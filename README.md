# Hydro Mart 💧

A mobile application for managing water delivery orders, built as a Final Year Project at Iqra University.

---

## Overview

Hydro Mart streamlines the water delivery process for both customers and delivery staff. 
Customers can place orders through the app, while the system automatically calculates 
the most efficient delivery route — reducing travel distance by approximately 25%.

---

## Features

- Order placement and tracking
- Real-time order management with Firebase
- Optimized delivery routing using Branch & Bound TSP algorithm
- Clean, intuitive mobile UI

---

## Tech Stack

- **Frontend:** Flutter (Dart)
- **Backend:** Firebase (Firestore + Authentication)
- **Algorithm:** Branch & Bound — Travelling Salesman Problem (TSP)

---

## Route Optimization

The app uses the Branch & Bound algorithm to solve the Travelling Salesman Problem 
for delivery routes. This achieved approximately 25% reduction in total travel 
distance compared to unoptimized routing.
